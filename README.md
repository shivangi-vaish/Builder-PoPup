## 🌟 What's New: Categories & Table Barcode Ordering

### 1. 🏷️ Smart Table Barcode & QR Ordering
* **Interactive Acrylic Table Stand**:
  * Every table (**Table T-01 to T-14**) has an authentic acrylic/wooden table stand with a high-resolution **2D QR Code** and **Code 128 linear Barcode** (`TWC-BLW-T-XX`).
  * **1-Tap Scan / Select**: Click **"Scan Table Barcode"** in the header or menu banner to open the table stand modal.
  * **Camera Scan Simulator**: Live camera HUD with animated red scanning laser line and scanner *beep* audio confirmation.
  * **Direct URL Check-in**: Append `?table=T-05` to automatically lock the session to that table.
  * **Barista Delivery Verification**: Table barcodes print directly on KDS tickets so table runners verify accuracy before delivery.
